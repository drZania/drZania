## 🚀 Featured Project

### 📚 DDRAG
**Drag, Drop, Retrieve, Augment, Generate**

A full-stack, local-first RAG application that allows users to upload documents and ask questions using locally hosted language models.

DDRAG started from my experience working with RAG systems during my internship. I built it as an independent portfolio project to explore backend architecture, document processing, semantic retrieval, and full-stack application development.

**Key features:**
- Document ingestion for PDF, DOCX, Markdown, and TXT files
- Semantic search using PostgreSQL and pgvector
- Local LLM inference and embeddings through Ollama
- Grounded answers with source attribution
- JWT authentication and user-scoped resources
- Persistent chat sessions and conversation history
- Responsive interface with light and dark themes
- Docker-based local development and automated testing

**Built with:** Python, FastAPI, PostgreSQL, pgvector, Ollama, React, TypeScript, Chakra UI, and Docker.

🔗 **[View DDRAG on GitHub](https://github.com/drZania/ddrag)**
